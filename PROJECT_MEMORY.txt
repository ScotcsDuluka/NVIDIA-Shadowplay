    - FACT
    - INTERPRETATION
    - UNKNOWN
    - RISK

14. Never claim WGC internal frame loss without direct evidence.
15. Do not treat FrameArrived as a guaranteed sustained-FPS signal.
16. Do not compare runs with different controlled conditions as if they were identical experiments.
17. Do not push unverified changes.
18. Build success does not equal behavioral equivalence.
19. Runtime behavior must be checked for UI/runtime changes.
20. Keep repository cleanup separate from production-engine work unless required.

[V4 — WGC EDGE-CASE]
==================================================

Status:
CLOSED WITH LIMITATION

Evidence:
- Test B: 600s
- Test C: 10 sessions × 15s
- Total observed frame events: 16,452

Test B:
- FrameArrived: 12,048
- Acquired: 12,048
- Consumed: 12,048
- DroppedByHarness: 0
- NoFrameReturned: 0
- ShutdownDiscarded: 0
- Average FPS: 20.08
- Median delta: 26.660 ms
- P95: 159.959 ms
- P99: 333.249 ms
- Max gap: 1.066397s
- Timestamp monotonic: TRUE
- PTS monotonic: TRUE
- Equal timestamps: 1
- Regressions: 0
- Negative PTS: 0

Test C:
- 10 × 15s sessions
- Aggregate: 4,404 frames
- DroppedByHarness: 0
- NoFrameReturned: 0
- ShutdownDiscarded: 0
- 0 equal timestamps
- 0 regressions
- 0 negative PTS
- All invariants hold
- FPS range: 4.20–43.43 FPS
- Max gap: 2.133333s

Important evidence:
- FrameArrived == Acquired == Consumed in all observed sessions.
- Downstream harness loss is eliminated.
- Harness is NOT proven to have zero upstream influence on WGC delivery.
- WGC internal pre-FrameArrived behavior remains UNKNOWN.
- Delivery gaps are delivery gaps, NOT dropped frames.
- Exact cause of delivery variability is UNKNOWN.
- Timestamp monotonicity/consistency is validated for tested scope.
- Timestamp accuracy/fidelity is not independently validated.

Experimental limitation:
- Test B and Test C used different display configurations.
- Therefore they are NOT a controlled comparison.
- Test B resolution/display configuration differs from Test C.
- Session 8 = 4.20 FPS is a single observed outlier and is not yet proven reproducible.

GLM-2 verdict:
CLOSED WITH LIMITATION

GLM-2SUB independent verdict:
CLOSED WITH LIMITATION

GLM-2SUB critical methodological findings:
- FrameArrived = Acquired only proves downstream harness losslessness.
- Cannot prove WGC never loses/suppresses frames before FrameArrived.
- Session 8 low FPS requires reproduction.
- Content condition was uncontrolled.
- Resolution mismatch prevents direct cross-comparison.
- Independent timing reference would improve timestamp fidelity validation.

Closed:
- Harness downstream losslessness
- Invariant correctness
- Timestamp monotonicity/consistency
- Session lifecycle behavior
- T0 reset behavior

Not closed:
- WGC sustained-FPS capability
- WGC internal pre-event frame loss
- Exact cause of delivery variability
- 144 FPS feasibility
- Long-term stability beyond 10 minutes
- Suspend/resume
- Multi-monitor/multi-adapter
- Other GPU generations/vendors
