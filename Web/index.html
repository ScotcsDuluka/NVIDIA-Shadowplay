Encoder & Capture

Modern capture APIs + hardware encoder status

Encoder Support

NVIDIA NVENC

Ready

Native in-app GPU encoding (production path): H.264 CBR/CFR, zero-copy D3D11 texture submission, proven stable in long-run stress tests.

Intel QSV

Partial

Intel QuickSync available through the FFmpeg engine path (hwmap derive_device=qsv) — validated on Intel hardware, experimental.

AMD AMF

Soon

AMD Advanced Media Framework encoder on roadmap.


API Capture

Windows.Graphics.Capture

Partial

Modern Windows 10/11 API via the FFmpeg engine (gfxcapture). Native overlay path still uses Desktop Duplication — WGC slot in the overlay menu is coming.

Desktop Duplication API

Recommended

The production capture path (native engine, zero-copy D3D11). Minimal latency, captures exclusive fullscreen (with limitations).

GDI Screen Grabber

Partial

Legacy fallback via the FFmpeg engine (gdigrab). CPU heavy — use only when needed.

Deep Dive

Modular Architecture

Each module with distinct border color — real stack components

CaptureEngine/

Core contracts and configuration: IVideoBackend / IEncoderBackend seams, config pipeline, engine logger. Every producer plugs in through these seams.

Capture — Ddagrab/

Production capture: DXGI Desktop Duplication on D3D11, zero-copy GPU frames with QPC presentation timestamps from the driver.

Encoder — NVENC/

Native in-app NVENC encoder: direct function-table binding (no FFmpeg wrapper), CBR/CFR, FORCEIDR first frame, GPU texture submission.

Audio — WASAPI/

Shared loopback engine armed on one common QPC timeline (T0) with video. System audio + microphone, gap-aware, honest drop accounting.

Live Mux — FFmpeg/

Named-pipe live muxer: H.264 + PCM stream into ffmpeg, fragmented MP4 (crash-safe), faststart finalize, drain-until-empty stop.

Overlay/

In-game borderless overlay (Alt+Z) with record controls, hotkeys (global RegisterHotKey), settings, gallery. No-Hook for anti-cheat compatibility.

Hub — NVIDIA API/

TCP hub on localhost:5000. Starts and keeps alive the whole app family (Capture, Overlay, Notifier) and carries the engine command channel.

Two Engine Regimes/

Duluka (native D3D11+NVENC) as production, plus an FFmpeg-engine path (ddagrab / gdigrab / gfxcapture, Intel QSV via hwmap) for wider hardware support.
