HARDWARE & APIS

Encoder & Capture Status

Exactly what works today — and what's on the bench

NVIDIA NVENC READY

Native in-app GPU encoding (production path): H.264 CBR/CFR, zero-copy D3D11 texture submission, proven in long-run stress tests.

Intel QSV PARTIAL

Intel QuickSync through the FFmpeg engine path (hwmap derive_device=qsv) — validated on Intel hardware, experimental.

AMD AMF SOON

AMD Advanced Media Framework encoder on the roadmap.

Desktop Duplication PRODUCTION

The production capture path (native engine, zero-copy D3D11). Minimal latency, captures exclusive fullscreen (with limitations).

Windows.Graphics.Capture PARTIAL

Modern Win10/11 API via the FFmpeg engine (gfxcapture). The native overlay path still uses Desktop Duplication — WGC slot in the overlay menu is coming.

GDI Grabber PARTIAL

Legacy fallback via the FFmpeg engine (gdigrab). CPU heavy — use only when needed.

DEEP DIVE

Modular Architecture

Real stack components — each module, one job

CaptureEngine/

Core contracts & configuration: IVideoBackend / IEncoderBackend seams, config pipeline, engine logger.

Capture — Ddagrab/

DXGI Desktop Duplication on D3D11, zero-copy GPU frames with driver QPC presentation timestamps.

Encoder — NVENC/

Native in-app NVENC: direct function-table binding, CBR/CFR, FORCEIDR first frame, GPU texture submission.

Audio — WASAPI/

Loopback engine armed on one common QPC timeline (T0) with video. System + mic, honest drop accounting.

Live Mux — FFmpeg/

Named-pipe muxer: H.264 + PCM into ffmpeg, fragmented MP4 (crash-safe), faststart, drain-until-empty stop.

Overlay/

Borderless Alt+Z overlay — record controls, global hotkeys, settings, gallery. Anti-cheat friendly.

Hub — NVIDIA API/

TCP hub on localhost:5000 — starts & keeps alive the app family (Capture, Overlay, Notifier).

Two Engine Regimes/

Duluka (native D3D11+NVENC) as production, plus an FFmpeg-engine path (ddagrab/gdigrab/gfxcapture, QSV via hwmap).
