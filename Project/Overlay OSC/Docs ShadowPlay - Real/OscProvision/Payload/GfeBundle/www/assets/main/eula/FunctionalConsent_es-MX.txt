GeForce Experience requiere datos para configurar tu tarjeta gráfica y la configuración de aplicación a fin de que disfrutes de la mejor experiencia de juego y creación de contenido. Necesitamos conocer el hardware de tu PC, el software para jugar y la configuración de la red, el uso de las funciones de GeForce Experience y la región geográfica.

Usamos estos datos para optimizar la configuración de tu aplicación, mejorar nuestros productos y servicios, y canjear códigos por juegos gratuitos.

Nuestra política de privacidad explica qué datos recopilamos, qué hacemos con ellos y los motivos legales para realizar estas acciones. Nunca vendemos tus datos.
