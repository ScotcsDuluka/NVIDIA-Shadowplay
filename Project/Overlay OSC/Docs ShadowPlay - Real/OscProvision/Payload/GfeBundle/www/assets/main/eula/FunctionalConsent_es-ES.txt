GeForce Experience necesita datos para configurar la tarjeta gráfica y la configuración de la aplicación para disfrutar de la mejor experiencia de juego y creación de contenido. Necesitamos conocer el hardware, el software para juegos y la configuración de red de tu PC, el uso de la característica GeForce Experience y la región geográfica.

Utilizamos estos datos para optimizar la configuración de tu aplicación, mejorar nuestros productos y servicios, y canjear códigos de juegos gratuitos.

Nuestra política de privacidad explica qué datos recopilamos, qué hacemos con ellos y la base legal para estas acciones. Nunca venderemos tus datos.
