AUDIO Tail-audio loss on Stop FIXED ✗last ~8s silent ✓drained fully, 0 bytes lost
Stable closed the audio pipe on a 3-second timer at Stop — any backlog was thrown away (measured: 1,530,240 B ≈ 8 s of silence at the end). OBT3 waits for the queue to actually drain before EOF, then finalizes.
AUDIO A/V clock REBUILT ✗two guessed clocks + 50 ms lead ✓one QPC clock · offset 0.000s
Stable synthesized video and audio timing separately and compensated with hand-tuned leads. OBT3 arms WASAPI on the same common QPC T0 as video and reads real device positions — verified 0.000 s offset on cold and warm sessions.
VIDEO Video-only recording FIXED ✗aborted at frame one ✓clean single-stream MP4
With audio disabled, Stable still declared an audio input to ffmpeg — nothing ever connected, ffmpeg exited -22 and no file was written. OBT3 treats "audio off" as no audio pipe at all.
UX / TRUST Recording pass reporting HONEST ✗could report fake success ✓drops fail the pass
Stable counted only producer-side bytes — the muxer could silently discard audio while the UI said pass=True. OBT3 surfaces mux-layer drops into the session result; any loss fails the pass and logs a warning.
CAPTURE Intel QSV encoder NEW —not available ✓experimental, validated
The FFmpeg engine path gained h264_qsv with CFR pacing and preset mapping (hwmap=derive_device=qsv on gfxcapture) — tested on real Intel hardware. NVIDIA NVENC stays the native production encoder.
UX / TRUST Hub-offline state FIXED ✗fake "Recording" forever ✓explicit "Hub Offline"
Stable flipped to Recording optimistically even when the engine link was down (the command was silently dropped). OBT3 checks the connection first and shows a clear offline state.
UX / TRUST Config write race FIXED ✗rewritten every second ✓writes only on your toggle
The launcher mirrored its UI toggle into config.json every tick, reverting external edits. OBT3 writes Overlay.UseOverlayEnabled only on real user action — config.json stays the single source of truth.
VIDEO NVENC H.264 · CFR 60 ✓p4 / CBR ✓same, FORCEIDR start
Same GPU, same settings, same quality — OBT3 adds a guaranteed IDR keyframe as the first frame of every session.
CAPTURE Hub auto-spawn + keep-alive NEW —manual juggling ✓engine family self-heals
The NVIDIA API hub starts and keeps the whole app family alive (Capture / Overlay / Notifier) every second — crash the engine and it respawns itself. Validated with repeated kill cycles.
UX / TRUST Regression suite NEW —ad-hoc ✓ConfigTruth 30/30 + ffprobe decode
Every claim on this page is backed by automated checks (Engine.ConfigTruth.Tests 30/30) plus forensic MP4 validation: ffprobe stream inspection, silencedetect tone placement and full -xerror decode passes.
CAPTURE Cross-GPU timing model NEW —NVENC-only assumptions ✓one model: NVENC + QSV
Both hardware paths share a single timing implementation — common T0, QPC anchors, mux offsets. No GPU-specific timestamp hacks; differences live at the correct abstraction layer.
CAPTURE Desktop Duplication (D3D11) ✓production ✓production, zero-copy
Unchanged — DXGI Desktop Duplication with driver QPC presentation timestamps remains the production capture path in both builds.
UX / TRUST Instant Replay buffer —not yet —in development
Still under active development in both builds — we won't pretend otherwise. It lands in a future update.
