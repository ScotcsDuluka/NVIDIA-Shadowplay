# Overlay Engine ใหม่: โฮสต์ osc (GFE Web Overlay) ด้วย WebView2

## เป้าหมาย (ไมล์สโตนแรก)
สร้าง exe ใหม่ **"NVIDIA Overlay Engine"** ที่ใช้เว็บแอป `osc` เป็น Overlay UI แทน WinForms:
- osc บูตและเรนเดอร์เมนูได้จริงในหน้าต่าง overlay โปร่งใส (toggle ด้วย Alt+Z / ข้อความ `open_overlay` จาก Launcher)
- ผูก Record Start/Stop, Instant Replay (start/stop/save) และสถานะการอัด กับ Engine เดิมผ่าน TCP hub เดิม (พอร์ต 5001)
- เป็น exe แยก เปิดขนานกับ Forms overlay เดิมได้ ใช้ธง `AppSettings.Overlay.UseOverlayEnabled` เป็นเงื่อนไขจด hotkeys

## ข้อเท็จจริงสำคัญจากการสำรวจ (เป็นฐานของแผน)
- osc คุยกับ host ทางเดียวคือ **`window.cefQuery`** (CEF message router) — บูตสำคัญสุดคือ `QUERY_WIN_NODE_INFO` → ตอบ JSON `{port, secret}` ของ local server (ถ้าไม่ตอบ หน้าจอเรนเดอร์แต่ idle/blank)
- ทุก event จาก host→page มาทาง **socket.io v2 + engine.io v3** (client แบบ polling) ที่ `http://localhost:{port}` พร้อม header `X_LOCAL_SECURITY_COOKIE`
- WebView2 Runtime ติดตั้งอยู่แล้ว (v152.0.4191.66) และยังไม่มีใครใน repo อ้าง WebView2/CefSharp เลย (greenfield)
- `TcpClientHelper.vb` เป็นสแตนด์อโลน — link มาใช้ซ้ำแบบ `<Compile Include ... Link>` ได้ทันที
- `docs/APP-LAYOUT.md:62` กันชื่อ `Overlay.Engine` ไว้สำหรับงานแบบนี้พอดี

## ขั้นตอนดำเนินการ

### 1) โครงสร้าง + ย้าย osc
- ย้าย `Overlay\osc\` → `Overlay.Engine\osc\` (ยัง untracked ใน git จึงย้ายได้ปลอดภัย ไม่มีโค้ดไหนอ้างอิง)
- สร้าง vbproj ใหม่ (AssemblyName "NVIDIA Overlay Engine", RootNamespace NVIDIA_Share ตามบรรดา exe ในตระกูล, `<Content Include="osc\**">` copy ลง output) + เพิ่มเข้า `Overlay\NVIDIA Overlay.sln`
- Link `Common\AppLayout.vb / AppLayoutStartup.vb / AppConfigShared.vb` ตาม pattern ของ Launcher

### 2) หน้าต่าง host + WebView2 + cefQuery shim
- Form ไร้ขอบเต็มจอ primary screen, TopMost, `WS_EX_TOOLWINDOW` (ไม่ขึ้น taskbar/Alt-Tab), ซ่อนด้วย Opacity 0 (เลียนแบบ `Base` เดิม)
- WebView2: `DefaultBackgroundColor = Transparent`, โหลดหน้าผ่าน `SetVirtualHostNameToFolderMapping("osc.local" → โฟลเดอร์ osc)` (l10n fetch แบบ relative จะทำงานอัตโนมัติ)
- Inject `cefQuery` polyfill ด้วย `AddScriptToExecuteOnDocumentCreated` (รันก่อนสคริปต์หน้า → vendor.js เห็น cefQuery ทันที) สื่อสารกับ host ผ่าน `chrome.webview.postMessage` + `PostWebMessageAsJson`
- คำสั่งที่ implement M1: `QUERY_WIN_NODE_INFO` (คืน {port, secret}), `QUERY_FULLSCREEN_STATE` (เช็ก fullscreen ด้วย WinAPI), `QUERY_OSC_SET_DISPLAY_RECTS` (เก็บ rect → ใช้ทำ hit-test), `QUERY_OSC_SET_PAINTING` (IsVisible ของ WebView), `QUERY_OSC_REGISTER_CLOSE_EVENT` (persistent — กด Esc/ปิดแล้ว push กลับ), `QUERY_OSC_DISPLAY_IS_DESKTOP_MODE`, `QUERY_WIN_OPEN_OSC/CLOSE_OSC`, `QUERY_READ/WRITE_SHARED_STORAGE`, `QUERY_LOAD_STRING_TABLE`, `QUERY_WIN_COPY_TO_CLIPBOARD`, `QUERY_HTTPSERVER_START` (stub ตอบ fail — OAuth ยังไม่ทำ), ที่เหลือ log + ตอบ error ให้ UI ย่อสภาพอย่างสวยงาม
- Click-through: `WM_NCHITTEST` ตอบ `HTTRANSPARENT` เฉพาะจุดที่อยู่นอก displayRects ทั้งหมด (model เดียวกับ GFE — หน้าจอเป็น OSD `pointer-events:none` แล้วส่ง rect ปุ่มมาให้ host)

### 3) OscControllerServer (หัวใจของฝั่ง server)
- `HttpListener` ผูก 127.0.0.1 พอร์ตว่างจากระบบ ตรวจ `X_LOCAL_SECURITY_COOKIE` ทุก request (loopback-only, ไม่มี firewall prompt)
- **REST subset**: `/uiReady`, `/state`, `/Record/Settings` (GET/POST ← config.json), `/Record/Enable` (POST true/false → RECORD_START/STOP), `/InstantReplay/Settings` + `/InstantReplay/Enable` (→ REPLAY_START/STOP), `/RecordPaths`, `/Language`, และ hardware/system-info ที่ boot resolve เรียก; ที่เหลือตอบ 404 JSON
- **engine.io v3 polling + socket.io v2** เขียนเองแบบมินิมอล (ไม่เพิ่ม dependency เสี่ยง ๆ): open packet `0{sid,upgrades:[],...}` → client อยู่กับ polling ตลอด, framing `<len>:<payload>`, ping `2`/pong `3`, socket.io `40` connect + `42["<channel>", <json>]`
- **push queue**: event ฝั่ง host (hotkey, TCP event) เข้าคิวต่อ connection แล้วส่งใน long-poll ถัดไป (cap 25s)
- ช่องทาง M1: `/ShadowPlay/v.1.0/WindowState` (`windowMsg: overlayToggle | showHotkeyMessage | dismiss | fullscreenTransition`), `/DisplayOscState`, `/Notification`, `/Hotkey`, `/Settings/v.1.0/Language`, `/PiplConfig/v.1.0/update` (push `{}` เพื่อคง server ว่าง — **offline-first ไม่มีการยิงออกนอกเครื่อง**)

### 4) TCP client + hotkeys
- Link `TcpClientHelper.vb` จากโปรเจกต์ Overlay มาใช้ verbatim, appName = "NVIDIA Overlay Engine"
- รับ/แปลงเหมือนที่ `Base.OnMessage` ทำ: `engine_ready` (re-pull status + PREWARM_FFMPEG), `engine_response`, `engine_state_changed`, `engine_recording_progress/saved/error` → แปลงเป็น REST state + socket.io push + Notification; `open_overlay` จาก Launcher → push `overlayToggle`
- ส่ง: `RECORD_START:<path>`, `RECORD_STOP`, `REPLAY_START:<sec>`, `REPLAY_STOP`, `REPLAY_SAVE:<path>;<dur>`, `engine_get_status` (bounded pull ตอน start เหมือนเดิม)
- Hotkeys: RegisterHotKey ชุดเล็ก (Alt+Z toggle, Alt+F9 record, Alt+F10 save replay, Alt+Shift+F10 replay toggle) — **จดเฉพาะเมื่อ `UseOverlayEnabled=true`** เพื่อไม่ชนกับ Forms overlay

### 5) Tests (ตาม convention runner เอกสิทธิ์ของ repo)
`Tester\test\Overlay\Overlay.OscEngine.Tests\` (Exe + Program.vb RunTest/RunSkip/Assert ตามแบบ Gallery.Video.Tests): engine.io v3 codec, socket.io v2 frames, REST router + auth cookie, แผนที่คำสั่ง (ข้อความ `[Send] ...|RECORD_START:...` ต้องตรง protocol เป๊ะ), displayRect hit-test

### 6) Build wiring + เอกสาร
- เพิ่ม classification ของ exe ใหม่ + โฟลเดอร์ osc ใน `_ProductTreeBin` (Directory.Build.targets) และ `scripts/layout.proj` ถ้าจำเป็น
- อัปเดต `docs/APP-LAYOUT.md` + README สั้นใน Overlay.Engine (วิธีรัน, ธง, ข้อจำกัด M1)

## ความเสี่ยง + แนวทาง
- **bundle ของ NVIDIA เป็น minified** — รูปทรง JSON บาง endpoint อาจไม่ตรง ใช้ WebView2 remote debugging (`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222`) ดู console/เน็ตเวิร์ก แล้วปรับ response ทีละจุด (`verboseLoggingEnabled:true` เปิดอยู่แล้ว) — นี่คือความไม่แน่นอนหลักของ M1
- ห้ามเปิด hotkeys ของสอง overlay พร้อมกัน (RegisterHotKey เป็น global) — ธง UseOverlayEnabled คือตัวคุม
- แก้ `osc/config.js` ให้น้อยที่สุด (M1 แทบไม่แตะ — server ว่างอยู่แล้ว)

## การตรวจสอบก่อนจบ
1. `dotnet build` solution ผ่าน + suite ใหม่ผ่านทั้งหมด
2. รัน exe → osc บูต เห็น main menu, toggle ได้, displayRects ทำให้คลิกเฉพาะปุ่มได้จริง
3. กด Record ใน osc → Engine อัดจริง (ไฟล์ลง Record_*.mp4), สถานะ/เวลาอัดไหลกลับมาโชว์ใน UI, Replay Save ได้ไฟล์
4. ปิด/เปิด Forms overlay สลับกันได้โดยไม่ crash (TCP hub broadcast ทนต่อ peer หลายตัวอยู่แล้ว)
