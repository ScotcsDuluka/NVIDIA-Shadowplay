## แผน: Host ใหม่ NVIDIA OSC.exe — โปร่งใส/Topmost/เต็มจอ ค้างไว้ตลอด (ไม่ปิด ไม่ซ่อน)

ซอร์สฐาน = `Project\Overlay OSC\NVIDIA OSC\osc_main.cpp` (มีครบ: OSR+ULW per-pixel alpha, zoom แท้, :3000, cefQuery) — งานหลักคือ**เปลี่ยนโมเดล visibility จาก "ซ่อนหน้าต่าง" เป็น "คลิกทะลุตามสถานะ openshare"**

### A. แก้ osc_main.cpp (โมเดลใหม่)
1. **เขียน `SetClickThrough(bool)` จริง** (ตอนนี้ stub ที่ `:560`): เติม/ถอด `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE` ผ่าน `SetWindowLongW(GWL_EXSTYLE)` + log ทุกครั้ง
   - ปิด = คลิกทะลุ 100% ข้ามโปรเซส + ไม่มีทางแย่งโฟกัส (ตามสเปก "ดูจาก openshare" — สถานะมาจาก `QUERY_WIN_OPEN_OSC`/`QUERY_WIN_CLOSE_OSC` ที่หน้าส่งหลังรับ openshare ผ่าน node :59011)
   - เปิด = ถอดทั้งสอง flag → คลิก UI ได้/โฟกัสได้ (พิมพ์ keyboard ได้เมื่อเปิด)
2. **บูต: โชว์ทันที ไม่ซ่อน** (`:1714-1741`): สร้างหน้าต่างพร้อม `WS_EX_TRANSPARENT|WS_EX_NOACTIVATE` (สถานะปิดตั้งแต่แรก) → `ShowWindow(SW_SHOWNOACTIVATE)` แทน `SW_HIDE` ที่ `:1739` (หน้าต่าง layered ก่อน ULW เฟรมแรก = มองไม่เห็นอยู่ดี ปลอดภัย)
3. **`WM_OSC_VIS` (`:1350-1394`)**: แขนง `w=0` (ปิด) = **ไม่ `SW_HIDE`** — สลับเป็น `SetClickThrough(true)` + คง timer 250ms / แขนง `w=1` (เปิด) = monitor-follow + `SetClickThrough(false)` + timer 16ms + Invalidate เหมือนเดิม
4. **`WM_CLOSE` (`:1453`)**: ไม่แตะอะไรเลย (ลบ CloseBrowser) — แอปไม่มีทางปิด (taskkill เท่านั้น — เผื่อตอน build)
5. **index.html โหลดค้างตั้งแต่บูต** = มีอยู่แล้ว (`CreateBrowserNow:1142` โหลดครั้งเดียว + watchdog กู้ about:blank `:1421-1432`) — toggle ไม่แตะ navigation เลย
6. **ย้าย path จาก dir เก่า**: `settings.cache_path`/`browser_subprocess_path` (`:1830,1834,1838`) เลิก hardcode → ใช้ `g_cfg.cache_path`/`g_cfg.subprocess_path` ที่อ่านจาก json (default ใน struct `:59-60` ย้ายมา deploy ปัจจุบัน) · `OSC_NEWCACHE=1` ต่อท้าย "2" แบบ relative
7. **Zoom/compositor/hook/page-server/cefQuery/fallback-chain: ห้ามแตะ** (zoom = `:608-623`+lock `:1000`+watchdog `:1434` — ระบบที่สั่ง "จำไว้ก่อน")

- `cachePath`/`subprocessPath`/`logFile` → ชี้ `build\NVIDIA ShadowPlay\Overlay OSC\NVIDIA OSC\` (ตอนนี้ชี้ dir เก่า "NVIDIA OSC Native" ที่ `:27,31,34` — CefCache ใหม่จะได้ไม่เจอ cache เก่า 138 ที่พัง)

### C. Build + Deploy
1. ปิด NVIDIA OSC.exe ก่อน build (ตอนนี้ไม่รันอยู่ — เช็คซ้ำตอนทำจริง; node แท้ NvNode/nvcontainer **ห้ามแตะ**)
2. MSBuild `NVIDIA OSC.vcxproj` Release|x64 (`C:\Visual Studio\MSBuild\Current\Bin\amd64\MSBuild.exe`) → PostBuild copy exe + `osc\` ไป deploy dir เอง
3. ตรวจ deploy dir มี CEF 73 runtime ครบ (libcef.dll, natives_blob.bin, snapshot_blob.bin, icudtl.dat, paks, locales — ยืนยันแล้วว่าครบ)

### D. ทดสอบ (ลำดับมือ ตาม checkpoint เดิม)
1. รัน exe → log ต้องมี `[zoom] fit=0.875 level=-0.732395` (จอ 1680×1050 ตรงค่าแท้) + หน้าโหลด + หน้าจอไม่มีอะไรโผล่ + `WindowFromPoint` ตรงกลางจอ = ไม่ใช่หน้าต่างเรา (คลิกทะลุตั้งแต่บูต)
2. node :59011 รัน → ถ้าหน้าไม่ต่อ socket เอง ใช้ CDP `socketService.connect()` (งาน backend ที่ค้าง — นอกสโคปรอบนี้) → `POST :59011/?hk=OpenShare` → เมนูลงจอ + คลิก tile ได้ + log "interactive"
3. OpenShare ซ้ำ → เมนูหาย แต่**หน้าต่างยังมีชีวิต** (`FindWindow("DulukaOscNative")` เจอตลอด) + คลิกทะลุจริง
4. ถ้า renderer crash-loop กลับมา → บันได fallback ที่มีอยู่: CefCache ใหม่อัตโนมัติ → `OSC_NOSHARED=1` → sw-render.flag → อ่าน VEH module log (Windhawk) + procdump
5. Checkpoint: commit ท้องถิ่น (branch Stable — ห้าม push ตามกติกาเหล็ก)
