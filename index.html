Prerequisites

System Requirements

Ensure your system meets these requirements for optimal performance.

IMPORTANT — Runtime Dependencies

.NET 8.0 Desktop Runtime — Required for application execution

.NET 4.8 Framework — Additional framework dependency

Operating System: Windows 8 / Server 2012 or newer (Windows 7 is NOT supported)

CAUTION — Known Limitations

Exclusive Fullscreen applications cannot be captured due to no-hook design on older Windows builds.

Please use "Borderless Windowed" mode in your games for reliable recording.

Some DRM-protected content (Netflix, etc.) cannot be recorded due to protection mechanisms.

TIP — Performance Optimization

For best performance, use NVIDIA hardware encoders (e.g., h264_nvenc) via FFmpeg.

Recommended Resolution: 1920 x 1080

Common Questions

Frequently Asked Questions

Everything you need to know about the project

Why No-Hook architecture? +
We avoid memory injection to ensure compatibility with anti-cheat systems and maintain system stability. This makes the app safer for online gaming.
Can I record DRM content like Netflix? +
Due to digital rights management, most streaming platforms block screen capture. This is a limitation of Windows itself, not our app.
What if I don't have an NVIDIA GPU? +
You can still use software encoding (x264) but performance may be lower. We plan to add Intel QSV and AMD AMF in future updates.
How can I contribute to the project? +
Fork the repository, make your changes, and submit a pull request. We welcome improvements, bug fixes, and documentation updates.
