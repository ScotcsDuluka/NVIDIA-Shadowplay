## A) SOCKET EMIT TRIGGER MAP (the 27 page listeners)

### A.0 Transport-level facts (index.js)

- **HTTP security middleware** `index.js:194-210`: CORS `Access-Control-Allow-Origin: *`,
  `Access-Control-Allow-Methods: GET,POST`, allow-headers
  `X_LOCAL_SECURITY_COOKIE, Content-Type, Content-Length`. **Every non-OPTIONS
  request with wrong/missing `X_LOCAL_SECURITY_COOKIE` header → 403
  `"Security token is invalid"`** (text/html).
- **Cookie generation**: `securityCheckEnabled = nvUtil.IsSecurityCheckEnabled()`,
  `securityCookie = nvUtil.GenerateRandom(16)` — **per-boot random, generated by
  the NvUtil.node native** (`index.js:188-189`). This is what
  `QUERY_WIN_NODE_INFO` hands the page ({port, secret}).
- **Socket handshake validation** `index.js:215-223`:
  `io.use(function (socket, next) { if (securityCheckEnabled &&
  socket.handshake.query.X_LOCAL_SECURITY_COOKIE != securityCookie)
  next(new Error('Security token is invalid')); else next(); })` — **the query
  param the page sends (app.js @81217) is validated here. Loose `!=` compare.**
- **No welcome burst**: `io.on('connection')` (`index.js:227-256`) only logs
  connect/reconnect/disconnect. **No state-sync payload is emitted on connect** —
  a freshly connected page must poll everything over HTTP.
- HTTP server: `httpServer.listen(portNumber, host)` (`index.js:725`).

`getJSONDataAndDo(req,res,cb)` → `api.<NativeCall>(doReply, content)` →
`doReply`: success = `res.writeHead(200[, {'Content-Type':'application/json'}])`
+ `res.end(JSON.stringify(data))` (data GETs) or `res.writeHead(200); res.end()`
(empty, mutations); error = `replyWithError` (see §D).

## C) SETTINGS PERSISTENCE MAP (where production really stores things)

**Headline: the node layer is essentially STATELESS for settings.** Nearly
every GET/POST forwards to a native `.node` module; persistence lives there
(DRS/registry/driver stores), not in node-readable files. Consequences for our
rebuild: wire-parity is what matters; we choose our own store.

| Setting group | Production storage | Evidence |
|---|---|---|
| Language | `nvUtil.SaveLanguage(lang)` — `NvUtil.node` native (NVSMC/registry) | index.js:656 |
| Experimental/beta flag | `nv-localstore` native store (`store.updateValue/getValue('autoGFEbeta')`) | NvAutoDownload.js:16, 843-848 |
| Record/IR/Broadcast settings, RecordPaths, overlays, webcam, mic, audio, desktop capture, highlights budget, hotkeys, HDR, concurrency | native `NvShadowPlayAPINode.node` / `NvBackendAPINode.node` (forwarded verbatim; JS keeps no copy) | every handler in NvShadowPlayAPI.js/NvBackendAPI.js |
| QuietMode2 / Nis2 / DeepDVC | native `NvBackendAPINode.node` | NvBackendAPI.js:735-949 |
| User token + GDPR consent | native `NvAccountAPINode.node` (`api.UserToken`, `api.SetPrivacySettings`) | NvAccountAPI.js:334-470 |
| PiplConfig (cloudvariables) | in-memory cache + 5-min re-fetch from gxtarget cloud; `%ProgramData%\NVIDIA Corporation\NvNode` passed as data path | NvPiplConfig.js:174-183, index.js:147 |
| Static config | `nodejs\config.json` (gxtarget clientId, ports, OTA URL) | index.js requires; inventory §3 |

## D) ERROR + ENVELOPE SHAPES

- **Success (data)**: `200` + `Content-Type: application/json` +
  `JSON.stringify(data)` — data is the NATIVE response passed through; there is
  **no envelope** (`{status,data}` never appears). Some handlers write
  `writeHead(200)` without the JSON header (GetConfig/SetConfig/GetHighlights —
  NvSDKAPI.js:322, 343, 525) — body is still JSON text.
- **Success (mutation)**: `200` with **empty body** (most POSTs), or `202`
  empty for async accepts (GameShare CreateSession NvGameShareAPI.js:117,
  Feedback NvBackendAPI.js:1478).
- **Parse failure**: `400` text/html + `e.message` (getJSONDataAndDo,
  NvAbHubAPI.js:76-84 — identical helper in every file).
- **Native/unknown error**: `replyWithError` → `400` if `err.invalidArgument`
  else `500` (or explicit httpCode arg), text/html + `err.message`
  (NvAbHubAPI.js:86-105; same helper everywhere).
- **Security rejection**: HTTP `403` `"Security token is invalid"`
  (index.js:198-202); socket handshake `next(new Error('Security token is
  invalid'))` (index.js:215-218).
- **GameShare missing-id**: `400` + `"Error: No session id in the request."`
  (NvGameShareAPI.js:145-149, 168-172).
- **204/no-body**: never used; empty-body successes are `200`/`202` with
  `res.end()`.
- **abHub GET /Status quirk**: passes `503` but answers `200` empty (§B.9).
