## Recent engineering highlights (pre-maintenance)

- `ba3c84f` — THE 60fps BUG: CFR loop was paced by the Windows timer
  quantum (~15.6ms), not the intended 75fps tick. Fixed with
  `timeBeginPeriod(1)` for the session. This also explains the historical
  "sometimes it syncs, sometimes it doesn't" behavior: running games raise
  the system timer resolution globally, quiet desktops do not.
- `16d101c` — audio lead calibration 100ms → 50ms (owner-measured).
- `1180392` / `0b31647` / `7b4ee06` — live-mux reliability: pipe death on
  first write error, audio queue starvation at 37Mbps, removal of
  `aresample=async` time-stretching.
- `90c37fe` — clock steering in AudioTap bounds crystal drift on long
  recordings.
