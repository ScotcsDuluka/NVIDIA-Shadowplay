## 0. Scope rule (decided up front)

**P13.5 removes the legacy SYSTEM-audio path only. The MIC path stays
legacy-tap (`AudioTap` + stopwatch offset) — porting mic to the device
clock is NOT in this phase.** In Device mode the mic already shares the
session with the v3 sys tap today, so nothing about the mic changes.
A full "mic → WasapiPositionCapture(non-loopback) + AudioTapDeviceClock"
migration is a **P13.6 candidate**, listed in §4 for future planning.

## 3. Decision recorded at staging time: delete the `AudioClockMode` flag?

**Recommendation: DELETE it in P13.5.** Rationale: the Legacy sys path no
longer exists to fall back TO — keeping the flag after its referent dies
manufactures a fake control. Revert story stays cheap: `git revert` of the
P13.5 commit restores a working Legacy path (it existed for weeks).
If OWNER prefers a runtime kill-switch instead, keep the flag and make
`"Legacy"` map to Legacy-branch *behavior* — but that means re-shipping
the whole legacy block, which defeats P13.5. Default: delete.
