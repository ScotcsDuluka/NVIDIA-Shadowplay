## Timing Data Analysis

### Key Instrumentation Points

1. **DdagrabBackend Frame Capture**
   - `DdagrabBackend: FRAME X CAPTURE TIMING:`
   - Shows when frames are captured from GPU
   - Key metric: `frameQpc100ns`

2. **CaptureSession Queue Dequeue**
   - `CaptureSession: FRAME X QUEUE DEQUEUE:`
   - Shows when frames are pulled from queue
   - Key metric: `frame.Diagnostics.CaptureTimeTicks`

3. **CFR Frame Selection**
   - `CaptureSession: CFR TICK X SELECTION DEBUG:`
   - Shows CFR target time vs actual selection
   - Key metrics: `targetQpc100ns`, `selectedTs`, `selectedLag`

4. **Encoder Input/Output**
   - `NvencEncoderBackend: FRAME X ENCODER INPUT/OUTPUT:`
   - Shows encoder processing time
   - Key metrics: `inputTick`, `outputTick`, `packet.PresentationTimestampTicks`

5. **Muxer Feed**
   - `CaptureSession: CFR TICK X MUXER FEED:`
   - Shows when packets reach muxer
   - Key metric: `packet.Metadata.PresentationTimestampTicks`

### Critical Timeline Analysis

```
Timeline T0 (session start)
├── _timelineStartTicks = Stopwatch.GetTimestamp() + 10ms (baseline)
├── _timelineStartQpc100ns = WasapiPositionCapture.StopwatchTicksTo100ns(_timelineStartTicks)
└── First frame target time = _timelineStartQpc100ns + (1 * 10000000L / FPS)
```

### Gap Calculation Formula

```
Recording start gap = 
    (First frame muxer feed time - Timeline T0) - 
    (Expected first frame time = 10000000L / FPS)
```

### Expected vs Actual Timeline

**Baseline (10ms delay):**
- Timeline T0 + 10ms + 16.67ms (60 FPS) = ~26.67ms
- If actual gap is 38ms, anomaly = ~11.33ms

**Experiment (no delay):**
- Timeline T0 + 16.67ms (60 FPS) = ~16.67ms
- If gap eliminated, confirms 10ms was the cause

## Data Processing Script

Create a PowerShell script to parse the timing logs:

```powershell
# Parse-TimingData.ps1
param($LogFile)

# Extract key timing values
$timingData = Select-String -Path $LogFile -Pattern "FORENSIC INSTRUMENTATION" | 
    ForEach-Object {
        $line = $_.Line
        if ($line -match "FRAME (\d+)") {
            $frame = $matches[1]
            [PSCustomObject]@{
                Frame = $frame
                Timestamp = $line
                Data = $line.Split(":")[2].Trim()
            }
        }
    }

# Analyze first 4 frames
$first4Frames = $timingData | Where-Object { $_.Frame -le 4 }

# Calculate timing deltas
$firstFrameTime = $first4Frames[0].Data
$lastFrameTime = $first4Frames[-1].Data

Write-Host "Frame 0: $firstFrameTime"
Write-Host "Frame 4: $lastFrameTime"
Write-Host "Delta: $((Get-Date $lastFrameTime) - (Get-Date $firstFrameTime))"
```

## Decision Matrix

| Test Result | Conclusion | Action |
|-------------|------------|---------|
| Baseline shows 38ms gap | Confirms issue exists | Run FPS matrix |
| FPS matrix shows scaling | Gap increases with FPS | Pipeline timing issue |
| Experiment eliminates gap | 10ms delay was cause | Remove 10ms delay |
| Experiment doesn't help | Deeper issue exists | Investigate pipeline |
