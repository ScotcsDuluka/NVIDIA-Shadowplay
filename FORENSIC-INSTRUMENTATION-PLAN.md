# FORENSIC INSTRUMENTATION PLAN

## Objective
Create observation-only instrumentation to trace timing from Capture → CFR → NVENC → Packet → MP4

## Requirements
- NO timing behavior changes
- Trace at least frames 0, 1, 2, 3, 4
- Include all critical timestamps
- Output in comparable format

## Target Layers
1. **Capture**: DdagrabBackend frame creation
2. **Queue**: Frame enqueue/dequeue timing
3. **CFR**: CaptureSession frame selection
4. **NVENC**: Encoder input/output timing
5. **Packet**: Encoded packet metadata
6. **Mux**: LiveMuxSession packet feeding


## Implementation Rules
1. Use Stopwatch.GetTimestamp() for tick timing
2. Use QueryPerformanceCounter() for QPC timing  
3. Log only for frames 0-4 to minimize overhead
4. Use existing logger infrastructure
5. No changes to timing logic
